  0개, 높이 0이었다. 구분선(`h-[11px] w-[1px] bg-gray-300`)과 랭킹 숫자의
  primary-500은 클래스에서 읽었다. 조건(`랭킹≠999 && 별칭있음`)은 모델
  테스트가 네 경우로 고정한다.
- **프로필 사진 분기를 보지 못했다.** 기본 아이콘(82×82)만 봤다. 사진
  분기의 `h-[80px]`·`object-cover`·랭킹 테두리는 클래스에서 읽었다.
  **둘의 크기가 2px 다른 것은 실측으로 확인**했다(아이콘에 크기 prop이 없다).
- **`오늘 식단` 3칸을 보지 못했다.** 두 회원 다 `등록 식단` 분기라 3칸
  블록이 DOM에 없었다. 칸 높이 88·`gap-2`·단식 체크 17×17은 소스 값이다.
- **`현재 등록된 수강권이 없습니다.` 카드를 보지 못했다.** 두 회원 다
  `course`가 있었다. 높이 127·gray-500·`TITLE_3`는 소스 값이다.
- **체크된 체크박스와 활성 `회원 삭제` 버튼 색을 보지 못했다.** 체크하면
  되돌릴 수 없는 삭제 버튼이 활성화되므로 **일부러 누르지 않았다.**
  `peer-checked:bg-primary-500` / `bg-point`는 클래스 값이다.
- **성공 토스트의 렌더를 보지 못했다.** 되돌릴 수 없는 삭제가 성공한
  뒤에만 뜬다. `check.svg` + `fill='var(--primary-500)'`는 소스 값이고,
  껍데기·간격은 에러 토스트와 같은 `toast()` 호출이라 공유한다.
